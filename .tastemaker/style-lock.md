# Style Lock — Foothill Digital

## Project
Foothill Digital — local digital agency for East Pasadena businesses.
Marketing landing page, single page, Long-Scroll Narrative macrostructure.

### Legal pairings
- **Text-safe (>=4.5):** text/on-primary, text/bg, text/surface, text/border, primary/on-primary, accent/on-primary, bg/primary, bg/accent
- **UI-safe (>=3.0):** surface/primary, surface/accent, primary/border, text/accent, accent/border, text/primary
- **Decorative (<3.0):** border/on-primary, bg/border, surface/border, surface/on-primary, bg/surface, bg/on-primary, primary/accent

## Typography
- Display: Fraunces (serif, 400-700, optical sizing)
- Body: Inter (sans-serif, 400-700)

## Density & spacing
- Section padding: space-32 (128px) for pivotal, space-24 (96px) for connective
- Card internal: space-6 (24px) minimum
- External gap > internal gap always

## Motion
- GSAP + ScrollTrigger
- Duration: 0.5-0.6s
- Ease: power2.out
- Stagger: 0.08s
- Reduced-motion: respected

## Structure
- Macrostructure: Long-Scroll Narrative (#4)
- Arc: Hook → Problem → Solution (3 bands) → How it works → Proof → Local → Close
- Archetypes: H2 split-hero, F1 alternating bands, F4 numbered steps, P3 quote, C2 statement+action

- Icons: Tabler set via Iconify — 6 icons in primary color
- Illustrations: none (photography-led project)
